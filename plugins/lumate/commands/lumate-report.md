Write a short report of what was done in this session and send it to my Lumate with the `lumate_report` tool.

- Two to six sentences: what was asked, what changed, what is left. Plain words.
- Pass `project` when there is an obvious project or repository name, and `links` for pull requests or tickets.
- Never include code, file contents, passwords, keys, tokens or anything from `.env` files. Leave such things out; Lumate removes
  secrets only on a best-effort basis, so do not rely on that.
- Only I can read the report in my private conversation with Lumate. Say in one line that it was sent.
